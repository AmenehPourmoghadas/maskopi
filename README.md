# Maskopi

*Swedish for "in cahoots": learning together, playing together.*

## About the app

As a parent, would you like to spend some evenings watching your own children learn through play?

Maskopi brings the two together. Teachers and parents describe the quiz they want to an AI assistant. Kids join with just a nickname and an avatar, and no personal data ever leaves the classroom.

**Free of cost!**

## How it works

1. **Create:** a teacher or parent chats with the Maskopi AI assistant, for example *"Make a 10-question quiz about planets for 8-year-olds"*, then reviews and approves the quiz.
2. **Share:** the host screen shows a game PIN and a QR code.
3. **Join:** kids scan the QR code or enter the PIN on a tablet, pick a nickname and an avatar, and they're in. No accounts, no passwords.
4. **Play:** questions appear with a timer and colorful answers. Faster correct answers score more points.
5. **Celebrate:** a live leaderboard after each question and a podium for the winners at the end.

## Privacy first

- Kids never create an account and never give their real name, photo or any personal data.
- Every AI-generated quiz is checked for child-appropriate content and approved by an adult before kids see it.
- Nothing about the players is stored after the game ends.
